# Support

Start with the repository's README for setup, usage, and troubleshooting. Follow any repository-specific support or contribution instructions.

For a bug report, use the repository's configured issue tracker. Include the affected version, steps to reproduce, expected and actual behavior, and relevant logs with credentials and private data removed.

Organization members can use the member view of the [Krosoft GitHub homepage](https://github.com/CollectCall) to find internal documentation, work trackers, and the team directory.
